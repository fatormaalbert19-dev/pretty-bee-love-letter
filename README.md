# Pretty Bee Love Letter

For Bee, from Berto.

This repository publishes the complete rose, pink and gold website using GitHub Pages from main, root. The production JavaScript, CSS and media live in the repository root and use relative paths.

Editable-Source-Code.zip includes the full React/TypeScript/Vite source project, media, build configuration, and instructions. The source in the archive uses media and assets subdirectories. Build it before deploying a source update, and preserve those folders or update the paths when using the flat layout here.

Music starts after tapping Okay, hear me out. The Yes button opens the prewritten WhatsApp response.
